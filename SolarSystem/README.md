# 3D Solar System Simulation (Using Three.js)

This project is a 3D interactive simulation of the Solar System built using Three.js — a WebGL-based JavaScript library for rendering 3D graphics in the browser.

## Features

- Realistic 3D model of the Sun at the center
- All 8 planets orbit independently around the Sun with orbital speeds proportional to reality
- Continuous orbital animation using JavaScript's animation loop
- Lighting from the Sun using a point light source
- Adjustable speed control to increase or decrease the entire system's animation speed
- Pause and resume functionality to control animation flow
- Smooth rendering with perspective camera

## Technologies Used

- Three.js
- HTML5
- JavaScript (ES6)

## File Structure
1. folder named SolarSystem
1.a. index.html file containing basic structure and UI
1.b. script.js file containing all the functionality


## How to Run

1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. The simulation will start automatically when you live it on your server. Use the speed slider or pause/resume button to interact.

## Controls

- System Speed: Adjusts the global speed of all planetary orbits individually
- Pause/Resume: Toggles the animation on or off

## Planets

This simulation includes:
- Mercury
- Venus
- Earth
- Mars
- Jupiter
- Saturn
- Uranus
- Neptune

Planet colors and orbit speeds are inspired by real data but simplified and scaled for performance and visual clarity.
